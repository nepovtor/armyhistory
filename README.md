# HIStory

Telegram Mini App с личными воспоминаниями по главам и частям.

## Версия без фотографий — 24 ноября 2026 года

Для чтения доступна глава «Первые дни службы»: 41 сцена в трёх частях, 19–25 ноября 1990 года. Текст взят из новой авторской редакции и учитывает уточнения от 23 ноября. На главной, обложке главы и в сценах оставлены места под будущие иллюстрации. Старые фотографии, рисунки и прежний рассказ удалены из актуального дерева проекта.

Работают переходы между сценами и частями, возврат, повторное чтение ранее открытых частей, дневник прогресса и начало заново. Выбор прочитанной части возвращает прогресс к её началу. Сервер хранит прогресс по пользователю; автономная версия — в браузере. Старые записи прогресса и купленные права сохраняются в базе; если сохранённой сцены больше нет, новый рассказ открывается с начала.

## Локальный запуск и проверки

Node.js 20+, внешних зависимостей нет.

```bash
npm run dev
# http://localhost:3000
npm test
npm run build:pages
```

`npm run build:pages` создаёт автономный `docs/index.html` с теми же текстом и движком чтения. Файл можно открыть в браузере или разместить на GitHub Pages. Платежи в этой версии недоступны; приватная карта и производственные референсы в HTML не включаются.

## Что остаётся планом

41 иллюстрация описана в `production/chapter01/storyboard.json` и файлах промптов; готовых изображений и видео нет. Анимационный фильм, озвучка, субтитры и платный Cinematic Mode относятся к будущему этапу. Текущая версия — готовый текстовый ридер с заглушками.

Продажа карты недоступна, пока нет её приватного файла. Отдельное право на карту за 15 XTR и учёт существующих покупок сохранены. Реальные новые платежи и платный фильм не включены.

## Структура

- `production/chapter01/source-author-2026-11-22.txt` и уточнения — авторские источники.
- `production/chapter01/script.md` — отредактированный рассказ в трёх частях.
- `production/chapter01/storyboard.json` — единый источник текста и ID 41 сцены; визуальная часть остаётся планом.
- `server/content.mjs` — каталог читательской версии из раскадровки.
- `server/engine.mjs` — переходы, возврат и прогресс; используется также автономной сборкой.
- `server/auth.mjs`, `server/storage.mjs` — авторизация и сохранение.
- `server/bot.mjs`, `server/payments.mjs` — Telegram и отдельный учёт Stars.
- `public/` — интерфейс, шрифты, значок и CSS-заглушки без фотографий.
- `tests/fixtures/story.mjs` — технический сюжет только для тестирования развилок.

Для серверного размещения нужны HTTPS, `BOT_TOKEN`, `APP_URL`, `NODE_ENV=production`, `DEMO_MODE=0` и постоянный `DATA_DIR`. Значения задаются через окружение или локальный `.env` по `.env.example`. Не коммитить токены и пользовательские данные.

Изменения публикуются в `feature/chapter1-photo-free`. Слияние в `main` и публикация сайта выполняются после проверки: существующий workflow GitHub Pages запускается при push в `main`. Обновление feature-ветки само по себе не меняет действующий сайт.
