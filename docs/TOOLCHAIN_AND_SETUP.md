# TOOLCHAIN_AND_SETUP.md — рабочая станция Codex

## A. Основной стек: устанавливать первым

| Утилита | Задача | Официальный источник / команда |
|---|---|---|
| Git | Ветка, история | `git --version` |
| Node.js 20+ | существующее приложение, будущий монтаж | `node --version` |
| FFmpeg / ffprobe | рендер/кодеки/проверки | `brew install ffmpeg`; https://ffmpeg.org/ |
| Blender 4.5 LTS / 5.x | Grease Pencil, 2D character rigs | `brew install --cask blender`; https://www.blender.org/ |
| Kdenlive | визуальный монтаж и контроль | `brew install --cask kdenlive`; https://kdenlive.org/ |
| Remotion | кодовый frame-accurate монтаж | https://www.remotion.dev/docs/ ; добавляет Codex только в отдельную production-подпапку после теста совместимости |
| Rhubarb Lip Sync | метки рта под реплики | https://github.com/DanielSWolf/rhubarb-lip-sync ; вручную выбрать официальную сборку MacOS / лицензию MIT |

Старт:

```bash
bash scripts/check-environment-macos.sh
bash scripts/check-environment-macos.sh --install-core
node scripts/validate-shotlist.mjs
npm test
npm run build:pages
```

Установка через `--install-core` требует уже работающего Homebrew. Скрипт сам не устанавливает Homebrew, не скачивает модель и не меняет приватные данные. Можно установить приложения через официальные сайты вместо Homebrew.

Дополнительно, если Codex не установлен: `npm install -g @openai/codex` и затем `codex --version` — официальная инструкция: https://github.com/openai/codex.

## B. Озвучка

1. **Живой рассказчик/актёр** (лучшее качество): запись с разрешением на использование, без несанкционированного клонирования голоса.
2. **Piper TTS**, локально, русский язык поддерживается, но качество/произношение/лицензия **конкретной модели** требуют проверки: https://github.com/rhasspy/piper ; каталоги `ru_RU`.
3. **Miragea Voice MCP**, ранее упомянут пользователем: https://github.com/RTY2345RR/miragea-voice-mcp ; может потребовать `MIRAGEA_API_KEY`, подписку и отдельную проверку разрешений на коммерческое использование. Не записывать ключ в Git.
4. **KokoroTTS** — опция, но сначала выяснить, обеспечивает ли выбранная модель качественный русский; не заменять этим проверенный русский голос без сравнения.

## C. AI-вспомогательные инструменты (НЕ обязательны)

- **ComfyUI**: https://github.com/Comfy-Org/ComfyUI — разбиение/восстановление слоёв, controlled img2img, отдельные image-to-video шоты. На NVIDIA GPU запускать только после проверки доступной VRAM/драйвера; на Apple Silicon модели могут быть существенно медленнее. Официальный сайт: https://www.comfy.org/download.
- **Image Story Video Wizard**: https://github.com/aaronyi97/image-story-video-wizard — skill оркестрации и проверки production стадий; **не видеогенератор сам по себе**. Подключить только если его `SKILL.md` и путь совместимы с установленным Codex. Не скачивать shell-скрипты из неизвестных источников.
- **lemo-opuscar**: если локально установлен на Mac, сначала прочесть `~/lemo-opuscar/plugin/skills/lemo-opuscar/SKILL.md` (путь проверить) и только потом интегрировать подходящие задачи. Не считать инструмент автоматически доступным в облачном Codex.
- Blender + Remotion обеспечивают детерминированные исходники, даже если AI-генерация недоступна. Качество сложных движений требует рисования/риггинга; никакого «одной кнопкой без человека».

## D. Проверка совместимости/лицензий

- **Remotion**: лицензия бесплатна для индивидуальных пользователей и подходящих небольших команд, включая коммерческое использование; при изменении размера организации/схемы хостинга свериться с https://www.remotion.dev/docs/license/pricing.
- **Rhubarb**: MIT, но не распространяется на голос, который ему скармливают.
- **Blender**: свободное ПО; произведённые пользователем анимации могут продаваться, если права на исходные материалы позволяют.
- **AI модели**: лицензия каждой модели и весов отдельно, плюс коммерческое право на референс и полученный контент. Не использовать незнакомые checkpoint без проверки лицензии.
- **Музыка/звуки**: никакой фон из YouTube/кино/советских песен без соответствующих прав. Лицензии, авторство и ссылки в `production/chapter01/assets-licenses.csv`.

## E. Разделение устройств и ресурсов

**Mac**: Node, Codex, Blender (2D), монтаж, FFmpeg, Git, при необходимости ComfyUI под Apple Silicon. **Ноутбук с NVIDIA**: при наличии подключённой и подходящей видеокарты — необязательный рендер AI-фрагментов. Не предполагать, что в Mac есть NVIDIA или что Windows/RTX-ноут уже подключён.

Обычно не стоит одновременно устанавливать десятки моделей и плагинов. Сначала добиться качественной анимации героя на трёх тестовых шотах и только потом расширять стек.
