# OPTIONAL_CODEX_SKILLS.md — подключение существующих skills

Подключай только после проверки, что Codex действительно читает указанные папки (вариант установки может меняться по версиям Codex). Не запускай чужой `curl | bash` без проверки.

## 1) Image Story Video Wizard

Официальный репозиторий: https://github.com/aaronyi97/image-story-video-wizard

Это **оркестратор этапов и проверки качества**, а не AI-движок создания анимации. Пример установки навыка в пользовательскую директорию Codex, если текущая версия поддерживает `~/.codex/skills`:

```bash
mkdir -p ~/.codex/skills
# Прочти README/SKILL.md репозитория ДО установки.
git clone https://github.com/aaronyi97/image-story-video-wizard.git \
  ~/.codex/skills/image-story-video-wizard
```

После клонирования сверить корневой `SKILL.md` и указания установки автора; не считать интеграцию работающей до проверки в Codex.

## 2) lemo-opuscar

Этот навык, судя по прежней установке, находится в `~/.agents/skills/lemo-opuscar/` и исходниках `~/lemo-opuscar`. Его наличие там **не означает**, что Codex имеет доступ. Проверить:

```bash
ls -la ~/lemo-opuscar/plugin/skills/lemo-opuscar
ls -la ~/.agents/skills/lemo-opuscar
```

Если у инструмента есть `SKILL.md` и он совместим с Codex, копируй соответствующую папку по официальным инструкциям, не дублируй весь репозиторий в проект. Применять только в пригодных задачах: концепты, структура работы, раскадровка; не заявлять, что он рендерит 2D, пока не проверено.

## 3) Miragea Voice MCP

Официальная страница: https://github.com/RTY2345RR/miragea-voice-mcp

Опциональная нейросетевая озвучка. Для облачного API может требоваться ключ и оплата. Устанавливать/подключать по **актуальному README**, лучше через `uvx`/`uv` при доступном пакете, но только после проверки имени, версии и MCP-конфигурации конкретного Codex. Ключ берётся из переменной окружения `MIRAGEA_API_KEY`, не добавляется в `.env` под Git и не передаётся в агентный текст.

## 4) Что реально считается «готовым»

- Codex обнаруживает skill и может прочесть инструкции.
- Тестовая команда skill выполняется локально без ошибок.
- Есть фактический результат (например, сценарий, аудиофайл или аниматик), который открылся, а не просто ответ «готово».
- Расходы API и право на коммерческую эксплуатацию проверены заранее.
